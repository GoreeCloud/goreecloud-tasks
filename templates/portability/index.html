Import a Todoist project

Upload one Todoist project CSV. GoreeCloud Tasks creates a new private project, imports tasks and subtasks, converts Todoist label tokens into project labels, and imports note rows as comments.

Migration boundary

Todoist author and assignee text is preserved as source metadata; it never creates or assigns GoreeCloud accounts. Natural-language or recurring dates, deadlines, durations, sections, and unsupported columns are preserved in task metadata rather than guessed into unsupported native fields.

Restore my archive

This recovery path restores a complete GoreeCloud Tasks user archive without overwriting or merging existing owned Tasks data. The archive username must exactly match your account, and every archived collaborator username must already exist locally.

Recovery boundary

Restoration is allowed only when your account has no existing owned Tasks projects, personal labels, or private personal tasks. User accounts are never created from an archive.
